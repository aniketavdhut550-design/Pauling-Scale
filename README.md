# ⚗ Pauling Scale

An interactive chemistry learning website based on the
Pauling electronegativity scale.

## 📌 About the Project

The Pauling Scale project helps students understand
electronegativity and chemical bonding through an
interactive web interface.

Users can explore the Periodic Table, view
electronegativity values, and determine the type of
chemical bond between two elements.

## ✨ Features

- 📖 Interactive Chemistry Concepts
- ❓ Question and Answer sections
- ⚗ Interactive Periodic Table
- 🔬 Pauling Electronegativity values
- 🧪 Chemical Bond Checker
- 🔵 Non-Polar Covalent Bond detection
- 🟦 Polar Covalent Bond detection
- 🔴 Ionic Bond detection
- 🐍 Python Flask backend
- 💻 HTML, CSS and JavaScript frontend
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- Flask
